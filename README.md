# Automated KPI Reporting Pipeline

**Data Analytics / Data Engineering / Software | Python, Pandas, SQLite (DuckDB-compatible SQL)**

All data is **SYNTHETIC** — generated by `pipeline.py` (seed 123).

## What it does
ETL pipeline: generates raw operations data, runs data-quality checks, quarantines bad rows, loads clean data to a SQLite warehouse (`warehouse/kpi.db`), and generates an automated KPI report (`results/kpi_report.md`).

## Run
```bash
pip install -r requirements.txt
python pipeline.py
```
